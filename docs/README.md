# Chumpy

Здесь собраны инструкции по установке Chumpy, добавлению подписок и настройке подключения.

Chumpy работает на Android 8.0 и новее, в том числе на Android TV. Для подключения понадобится подписка или конфигурация от вашего провайдера.

Начните с [установки](getting-started/install.md), затем [добавьте подписку](getting-started/subscriptions.md).

Если подключение не работает, загляните в [решение проблем](help/troubleshooting.md).
