# Установка

1. Откройте [последний выпуск Chumpy на GitHub](https://github.com/ChumpyXray/Chumpy/releases/latest).
2. Скачайте APK для своего устройства.
3. Откройте файл и подтвердите установку. Если Android попросит разрешение на установку из этого источника, разрешите её.
4. Запустите Chumpy и [добавьте подписку](subscriptions.md).

## Какую сборку выбрать

| Сборка | Для каких устройств |
| --- | --- |
| ARM64 | Большинство современных телефонов. Для телевизора проверьте архитектуру установленной Android-системы. |
| ARMv7 | Устройства с 32-битной Android-системой. |
| x86_64 | Устройства и эмуляторы на x86_64. |

Разрядность процессора и Android-системы может различаться. Если APK не устанавливается, уточните архитектуру системы и проверьте, что на устройстве Android 8.0 или новее.

## Обновление

Установите новый APK поверх приложения. Если Android сообщает о несовместимой подписи, проверьте источник обеих сборок. Перед удалением приложения сохраните ссылки на подписки и нужные конфигурации: локальные данные могут быть удалены вместе с ним.
